# TrackMySci

TrackMySci is a web application developed for graduate students at Southern Illinois University Edwardsville (SIUe) to track scientific literature they read. With TrackMySci, students can organize their academic readings by adding summaries, ratings, and tags to each piece of literature.

## Features

- **Add Scientific Literature**: Users can input details for each piece of literature they read.
- **Summarize**: Write summaries to capture key insights or important points from each article.
- **Rate**: Give each article a star rating from 1 to 5 to easily track the most impactful or relevant studies.
- **Tagging**: Add tags to categorize literature for better organization and filtering.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/TrackMySci.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd TrackMySci
   ```
3. **Install dependencies** (if applicable):

   ```bash
   npm install
   ```

4. **Start the application**:
   ```bash
   npm run dev
   ```

**This application will be deployed to trackmysci.com**

## Usage

Once the app is running, users can:

1. **Log in** to access their personal dashboard.
2. **Add new articles** to their reading list, providing key information such as the title, author, publication date, and journal.
3. **Write a summary** for each article to capture the main takeaways.
4. **Rate each article** on a scale of 1 to 5 stars to indicate its usefulness or relevance.
5. **Add tags** to organize articles by categories (e.g., "Machine Learning," "Biology," "Literature Review").
